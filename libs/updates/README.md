# Article update rules

This shared library reconciles approved structured knowledge with new model
contributions and checks trusted update bases. It reads article files and
history without writing the vault. The compiler, reviewer, and writer use the
same claim/removal contract; approval/apply cannot turn an additive proposal
into an unreviewed replacement.

See [accumulated knowledge](../../docs/ACCUMULATED_KNOWLEDGE.md) for reconciliation,
base revisions, review JSON, retained evidence, and compatibility behavior.
